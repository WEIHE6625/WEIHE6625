## 🚀 Featured Projects

### 📈 Algorithmic Cryptocurrency Trading Bot 
* **Tech:** Python, PyTorch, Binance REST APIs, WebSockets, Reinforcement Learning
* **Description:** Developed an automated trading bot using Temporal Fusion Transformers for multi-target trend and volatility decomposition. Streams real-time tick data and historical multi-year BTC/USDT candlestick data directly via Binance WebSockets.

### 🧠 Deep Learning & NLP Pipelines
* **Skincare Sentiment Analysis:** Developed an aspect-based sentiment analysis model using Python and Transformers (90% accuracy), deployed via a Streamlit interface. Fine-tuned BERT using Optuna hyperparameter optimization for joint aspect and overall sentiment classification.
* **News Article Simplification:** Engineered an NLP pipeline using PyTorch and HuggingFace Transformers, implementing chunked context summaries and single-prompt generation routines to simplify complex articles.

### ⚙️ Systems & Software Engineering
* **Java Book & Inventory Management System:** Built a backend management system leveraging custom `TreeMap` structures to optimize search operations. Features automated order status workflows and generated ASCII bar chart reporting modules.
* **Smart Parking System (IoT):** Developed an ESP32 RFID hardware module using Arduino C++ to capture data, linked to a Flask backend and Firebase real-time database.

### 🛍️ Web & Full-Stack Applications
* **Malaysia Price Comparison App:** Designed UI and authentication workflows, utilizing Flask to aggregate external product pricing APIs and Supabase for backend storage.
* **Real-Time Financial Dashboard (Internship - Techtics Solutions):** Built a Vue.js and Laravel PHP automated trading interface, integrating WebSockets to stream live market data.
